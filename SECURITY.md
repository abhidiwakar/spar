# Security

## What this app does

Spar runs **your** Python or JavaScript on this machine with **your** user privileges. There is no OS sandbox. Treat Run and Submit like running a script in a terminal.

Do not paste code you do not trust.

Optional AI review sends the current solution to OpenAI or a local Ollama host. The OpenAI key is stored only in the local SQLite database and is never included in progress snapshots.

## Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/abhidiwakar/spar/security/advisories/new) instead of a public issue.

Do not open a public issue that includes a working exploit, a leaked key, or steps that damage a user's files.
